Run to Run Wx. Data: NOAA GFS and the GEFS mean via the NOAA Open Data Dissemination program on AWS; NOAA AIGFS and the AIGEFS and HGEFS means from NCEP NOMADS. The ECMWF IFS, AIFS and ENS mean maps are based on data and products of the European Centre for Medium-Range Weather Forecasts (ECMWF), via Google Cloud, published under CC BY 4.0. Run to Run Wx has modified that data: cropped to North America and re-encoded, with wind speed and direction, 6-hour precipitation and snowfall, precipitation type and vorticity derived from it, and the ensemble's 50 members averaged. ECMWF does not accept any liability whatsoever for any error or omission in the data. The GEM maps use the Global Deterministic Prediction System (GDPS) from the MSC Datamart. Data Source: Environment and Climate Change Canada, under the ECCC Data Servers End-use Licence; Run to Run Wx regrids it to this map's 0.25° grid and derives wind speed and direction, precipitation type and vorticity. The ICON maps are based on data from Deutscher Wetterdienst (DWD), from its open data server, published under CC BY 4.0: gridded data reproduced graphically, regridded from ICON's icosahedral grid to 0.25° and re-encoded, with 500 mb heights, wind speed and direction, 6-hour precipitation and snowfall, precipitation type and vorticity derived by Run to Run Wx. Basemap: Natural Earth.
