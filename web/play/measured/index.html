    Run to Run Wx. Measured: NOAA's URMA (station observations analysed onto a 2.5 km grid) and MRMS (radar rainfall corrected to rain gauges). Run to Run Wx averages them onto the model's 0.25° grid, blurs both of a round's maps lightly (the measured one a little more, until the two are equally detailed) and moves the forecast map to the measured average over land, so neither sharpness nor a steady offset gives either away. Forecasts: NOAA's GFS. Basemap: Natural Earth.
